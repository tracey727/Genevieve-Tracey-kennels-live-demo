# Deployment steps

## Test on the computer

1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click `index.html`.
4. Open `employee.html` in another browser tab for the rounds demonstration.
5. Open `transport.html` for the driver demonstration.

## GitHub

1. Create a new empty repository.
2. Upload the contents of this folder, not the outer folder itself.
3. Confirm `index.html` appears at the repository root.
4. Commit the files.

## Vercel

1. Add New Project.
2. Import the GitHub repository.
3. Framework Preset: `Other`.
4. Root Directory: `./`.
5. Build Command: leave blank.
6. Install Command: leave blank.
7. Output Directory: leave blank.
8. Deploy.

## Important

The deployed static demo does not securely share records between different physical phones. Each device has its own browser data. A secure backend is required before real kennel, owner, employee, medical or incident data is used.
